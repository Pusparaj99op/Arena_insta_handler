# voice.md

The single most important file in this repo. Every skill and every automated
reply reads it. Ten minutes here is the difference between scripts you shoot and
scripts you rewrite.

The format is the same as the one in `instagram-agent-skill`, so anything
already filled in there can be pasted across.

A line you would never say out loud is not a draft, it is a retake.

The model that writes your DMs reads the section above. The text-to-speech
model reads this section. Keep it short and literal: it is direction, not prose.

- **Voice provider:** (elevenlabs / openai / local)

- **Accent:** (Indian English / neutral American / British)
- **Delivery:** (explain like a patient teacher to one person / calm and dry /

- **Pace:** (measured. a little slower than conversation, because the viewer is
